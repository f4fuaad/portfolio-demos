Method & definitions

  • Actual-only rule: all KPIs, bars, donut and tables use Mob Plan Type = “Actual” only. The plan-comparison line chart is the exception — it shows Base Plan, Estimated (_1FC, labelled “Forecast” in the brief) and Actual together.
  • Rows: sheet “Manning Chart”, headers row 13, data rows 14–24. Only 6 rows carry a VS ID (VS-21317-P001 / VS-21317-P002 × _0BP / _1FC / _2AC); blank VS ID rows are ignored. Blank fields are shown as “—” / “Not recorded”, never filled in.
  • Man-days: monthly columns are NETWORKDAYS.INTL working days (weekend code 16 = Friday only, Qatar) between Adjusted Start/End Mob, capped to each calendar month. Unpivoted Jul 2022–Dec 2028 in the extracts; the line chart shows Jan–Dec 2023.
  • On Site Today: Start Mob ≤ TODAY ≤ End Mob on Actual rows, with TODAY = 15 Nov 2026 (the file’s “Date actual” cell). Actual rows have no dates, so the result is 0.
  • Next 30 days: 16 Nov 2026 – 15 Dec 2026, Actual rows only. No mobilizations start or end in that window.
  • Naming discrepancy: the _1FC rows are labelled “Estimated” in the file, not “Forecast”. The build pack maps Estimated → Forecast so the brief’s chart labels still work.
  • Not used: the “Daily” sheet is formula-driven and returns #VALUE! / blank on this stripped template; the “Global Bilan” totals above are a 16 Jun 2026 snapshot, not current KPIs.
