How this runs live — no manual chasing

Microsoft 365 only

Built for a corporate EPC setup: one SharePoint list everyone updates, Power BI on top, and Power Automate doing the reminders. No extra software, no n8n, nothing for IT to block.

1 · SourceSharePoint list

Completions team adds each system at handover — tag, vendor, warranty start & end, PO. One shared copy, no emailed Excels.

→
2 · DashboardPower BI (this view)

Refreshes automatically from the list. Management sees expiries, open claims and vendor performance in one place.

→
3 · AlertsPower Automate

Sends the reminders and the Monday report on its own — Outlook + Teams, with a Planner task for overdue claims.

90 days

Heads-up — email to warranty owner: check the system, log any defects as claims before cover ends.

30 days

Urgent — Teams message + Planner task. Open claims with that vendor are listed in the same alert.

Every Monday

Weekly PDF — this dashboard sent automatically to project & completions leads. No one builds it by hand.

Same pattern already proven on the NFE Vendor Manning dashboard: SharePoint in, Power BI out, refresh in minutes instead of a day of Excel work.
